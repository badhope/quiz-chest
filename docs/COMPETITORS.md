# 同行拆解与能力缺口

题小星不需要成为另一个考试宝。它的定位是**只处理用户自己的题库、默认离线、数据留在本机**。所以这份矩阵不按「谁功能多」排序，而按「自有题库从导入到复习的闭环」找缺口。

## 一、对比对象

选四个代表，而不是把应用商店里的刷题 App 全列一遍：

| 产品 | 它最强的地方 | 它和题小星的重叠 |
| --- | --- | --- |
| 考试宝 | 文档导题、题型覆盖、组卷和在线考试 | 自有题库 + 刷题 + 模拟考 + 错题 |
| 粉笔 | 公考教培生态、错因归因、模考排名 | 题库 + 错题本 + 模考 |
| Anki | FSRS 调度、卡片模板、跨端同步 | 长期复习与记忆管理 |
| Quizlet | 学习模式多、自适应 Learn、游戏化 | 学习集 + 背题 + 测试 |

## 三、这一版先补什么

2.1.0 选择四个能形成闭环、且不会把应用做成臃肿平台的功能：

1. **Word / TXT / Markdown 导入**：补上考试宝最常用的文档入口。只支持题号模板，不假装能读懂任意排版；缺答案、选项不足会逐条报错，不静默丢题。
2. **背题模式**：补考试宝、Anki、Quizlet 都有的「先看答案再做题」场景。不判分、不写正确率、不占 FSRS，避免把浏览记录污染成掌握度。
3. **错因标签 + 题笔记**：对齐粉笔的错因归因。四类错因由用户自己标，不自动猜测；笔记最多 200 字，只在本机，随备份走。
4. **未来 7 天复习预测**：把 FSRS 的到期时间从「今天到期 N 道」扩展成一周负载，用户能提前安排，而不是每天打开才知道要复习多少。

## 四、还没补的，按优先级排

| 优先级 | 能力 | 为什么现在不做 |
| --- | --- | --- |
| P1 | 填空、简答、排序、连线 | 需要改答题数据模型和判分链路，单独做 2.2，不能塞进 2.1 草草上线 |
| P1 | PDF 文本导入、图片 OCR | PDF 解析和 OCR 会显著增加安装包；先看 Word/TXT 的真实使用率 |
| P1 | 模考分数、及格线、按题型赋分 | 当前组卷已能限时，但分数报告要统一分值口径，单独做 |
| P2 | 全题卡 FSRS（不只错题） | 需要为每道题建复习卡，数据迁移面大；先把错题复习做扎实 |
| P2 | 标签掌握度、强弱项热力图 | 依赖全题卡数据，不能拿错题数据冒充掌握度 |
| P2 | 本地 AI 生成变式题 / 出卷 | 本地模型质量和速度都不稳定，先不做「看起来智能」的假功能 |
| P3 | 账号云同步 | 与「数据留在本机」冲突；只考虑可选的端到端加密文件同步，不做账号体系 |
| 不抄 | 题库交易、课程直播、排名、AI 防作弊 | 是平台生意，不是离线个人题库的必需能力 |

## 五、完整的定义

对题小星来说，「完整」不是功能数量追上考试宝，而是这五步都不掉链子：

1. 用户能把已有的 Word / Excel / CSV / JSON 题库带进来，并且知道哪几题没通过校验。
2. 题库能按顺序做、按考试做、按错题做，也能先背题再做题。
3. 错题能按记忆曲线回来，用户能标错因、写一句自己的话。
4. 复习量能提前看见，不用每天打开才知道今天要花多久。
5. 所有数据都能导出、备份、换机，不依赖任何账号。

这五步里，2.1.0 补了第 1、2、3、4 步的一部分；第 5 步原本就有。下一步 2.2 把题型补齐，才算真正覆盖「自己的题库」而不是「选择题题库」。
