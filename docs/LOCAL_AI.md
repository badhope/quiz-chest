# 本地 AI 讲题

题小星不内置模型权重，也不把题目发给云端 API。可选的本机模型讲解接在答题解析区，默认关闭；模型挂了，题库自带解析仍然是完整兜底。

「小星建议」和本地模型是两套东西：前者是 `src/lib/coach.ts` 的本地学情规则，读记录、错题和进度；后者是用户自己启动的 OpenAI 兼容服务，只负责解释当前题。

## 已经落地的部分

```
答题解析区「问小星」
        │
        ▼
src/lib/tutor
  ├─ config.ts       默认关闭、默认端点、旧备份补字段
  ├─ protocol.ts     端点校验、题目上下文、响应解析
  └─ transport.ts    Web fetch / Android CapacitorHttp
        │
        ▼
http://127.0.0.1:<port>/v1/chat/completions
```

- **默认关闭。** 设置页有独立开关；不开启时答题页不会发任何请求，只显示题库解析。
- **只允许本机回环。** endpoint 只接受 `127.0.0.1`、`localhost`、`::1`，带账号、非 http(s)、局域网或公网地址都会被拒绝。这不是提示，是硬校验。
- **只发当前题。** 请求里只有题干、选项、学生选择、正确答案、题库解析和本次追问；不传题库名、collectionId、历史记录、错题本、备份或图片 URL。
- **配图题说明清楚。** 当前接口不发图片二进制，只告诉模型“本题含配图，图片未发送”，避免模型假装看过图。
- **超时降级。** 单次请求 45 秒；超时、HTTP 错误、空响应或网络失败都回到题库解析，答题页不阻塞，并提供「再试一次」。
- **输出按纯文本渲染。** 不执行 HTML，不接 `dangerouslySetInnerHTML`；清理控制字符并限制 6000 字。
- **对话不落库。** 弹层关闭即清空，不写学习记录、不参与统计；换题也不会带上一题上下文。
- **提示模式。** 「只给提示」不把正确答案和题库解析放进 prompt，避免模型直接报答案。

## 使用方式

1. 在自己的电脑或手机上启动 Ollama / llama.cpp 的 OpenAI 兼容服务。
2. 设置页打开「本地 AI 讲解」，填接口地址与模型名，点「测试连接」。测试只发送固定探测文本，不发送题目。
3. 正常答题并提交，解析区出现「问小星」；打开后先展示题库解析，再请求本机模型。
4. 可以继续追问；「只给提示」会单独走提示 prompt。

### 桌面端

```bash
ollama pull qwen2.5:3b
ollama serve
# 默认监听 127.0.0.1:11434
```

桌面 Tauri 的 WebView 也要遵守 CORS。Ollama 默认可能只允许自己的来源；如果连接被浏览器拦下，按 Ollama 文档设置 `OLLAMA_ORIGINS`，把应用来源加进去，而不是把端点改成公网地址。

### Web / PWA

浏览器直接 `fetch` 本机服务，需要本机服务返回 CORS 头。设置 `OLLAMA_ORIGINS=http://localhost:5173`（开发）或实际部署来源即可。应用本身不代理请求。

### Android

- 原生壳走 Capacitor `CapacitorHttp`，不经过 WebView 的 CORS/mixed-content 限制。
- `android/app/src/main/res/xml/network_security_config.xml` 只为 `127.0.0.1`、`localhost`、`::1` 打开 cleartext；其他 HTTP 仍按 Android 默认拒绝。HTTPS 公网不受影响，但应用不会把题目发过去。
- APK 不打包模型权重。Android 上没有默认就能跑的 Ollama：需要用户自己装本地推理 App 并暴露回环端口，或后续集成 llama.cpp / MNN 的 AAR。当前版本只完成 HTTP 适配，没有内置推理 SDK。

## 已知限制

- 没有模型文件，没有一键下载模型，也没有内置推理运行时。
- 非流式返回；长回答要等完整响应，首次加载模型可能接近超时上限。
- 不发图片，配图题只能解释文字部分。
- 不自动改答案、不自动判分、不生成新题，也不把错题归档交给模型。
- Android 的回环 HTTP 已写进配置，但当前环境没有 KVM/adb 真机，系统 WebView、厂商后台限制和真实 Ollama App 仍需发布前手工验收。
- 浏览器/桌面端需要本机服务允许 CORS；这不是应用能单独绕过的事情。

## 不建议做的事

- 不要把错题本、备份、账号 token 塞进 prompt。
- 不要用模型输出覆盖正确答案或判分。
- 不要把「AI 讲解」设成默认路径；题库解析必须始终先可用。
- 不要在未验证的机型上宣称“已适配本地大模型”。
