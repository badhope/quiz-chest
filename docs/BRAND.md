# 品牌手册：题小星 · TiXing

这份手册不是招商材料，只定下对外说话和露脸的规矩。改品牌时先看这里，再动页面、图标和文案。

## 一句话

**自有题库，离线也能练。**

英文：**Your question bank, offline.**

这句话里的重点不是「AI」，是「自有」和「离线」。题小星不卖题库、不做账号、不接云端；模型可以接本机的，但判分、错题和调度永远在设备上。

## 定位

给老师、学生、备考者和培训组织者用的本地题库工作台。用户带着自己的 Excel、PDF 文字层、Word 或题号模板进来，练题、背题、模考、错题复习、组卷打印，数据留在本机。

不把自己说成「AI 刷题神器」，也不拿「智能」当主卖点。AI 只是可选的讲解入口，不是题库的来源。

## 名字

- 中文正式名：**题小星**
- 英文名：**TiXing**
- 包名与身份：`com.tixing.offline.ai`，不再改动
- 标识字：**题**，放在印章形圆角方块里

英文语境里第一行写 `TiXing`，第二行再出现「题小星」；中文语境反过来。不要写成 `Ti Xing`、`Tixing` 或 `题小星题库`。

## 视觉

色板来自纸张和印章，不来自科技蓝紫：

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 印章红 | `#A8442A` | 主按钮、重点句、品牌线 |
| 纸白 | `#F4F0E7` | 页面底色 |
| 纸面 | `#FBF9F3` | 卡片与弹层 |
| 墨色 | `#1D2523` | 正文与标题 |
| 苔绿 | `#3D5A45` | 正确、完成、辅助状态 |

标题用 `Noto Serif SC` / 宋体，正文用 `Noto Sans SC` / 系统无衬线。不要在标识上加渐变、发光、长阴影或英文缩写；印章本身就是标识。

截图只拍真实界面，不用拼贴的假 UI，不把浏览器模拟说成真机。桌面 1440×960，手机 390×844，保持同一套页面状态和同一版文案。

## 语气

- 说具体的事：能导入什么、在哪一步失败、数据存在哪。
- 不承诺做不到的：简答只做关键词命中，不冒充语义评分；扫描件不内置 OCR，就说清楚。
- 不制造焦虑，不写「再不看就晚了」。
- 不用「赋能」「一站式」「颠覆」这类词。写「闭环」时，要能指出是哪几步。

## 不做什么

- 不卖题库，不做题库交易。
- 不做账号、云同步、排名和直播课。
- 不把「AI」印在应用名上。
- 不用别人的题库截图冒充自己的界面。
