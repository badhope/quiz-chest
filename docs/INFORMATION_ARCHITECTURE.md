# 信息架构与导航设计

## 一、问题：分类一多，用户就迷路

题库天然是三层结构：**领域 → 学段/子类 → 题库**。多数刷题产品把三层压平成一张长列表，用户必须逐条扫读标题才能判断「这个是不是我要的」。列表的通病是：

1. **没有可推断性**：看到「高等数学」不知道它在哪个领域，也不知道还有没有别的相关题库。
2. **筛选器堆叠**：领域 + 难度 + 类型 + 考试并排摆，用户要先理解筛选逻辑才能用。
3. **入口单一**：只能「先找题库再练习」，无法「先说目标，让系统安排」。

本项目的设计目标是：**任何用户在任何状态下，最多两步就能落到具体题目上。**

## 二、三条互斥的找题路径

首页不铺题库，而是先问「你现在是什么状态」，给出三条路：

| 路径 | 面向的用户心理 | 落点 | 交互 |
| --- | --- | --- | --- |
| 路径一 · 我有明确目标 | 「我要考研 / 面试 / 考证」 | `/goals` 目标方案 | 每条路线是一串有序题库步骤，按周推进 |
| 路径二 · 我想按领域找 | 「我想看看有哪些题」 | `/catalog` 主从钻取 | 左树选领域 → 学段 → 右侧题库卡 |
| 路径三 · 不知道练什么 | 「随便练练，别让我选」 | `/strategy/daily` 策略练习 | 系统按薄弱项自动配题 |

三条路径互不重叠：目标路径给「计划感」，领域路径给「掌控感」，策略路径给「零决策成本」。用户永远不需要在同一个界面里同时处理这三种诉求。

## 三、领域页：主从钻取（Master–Detail）

不使用平铺列表，而是左侧固定领域树 + 右侧内容区：

```
┌─────────────┬──────────────────────────────────┐
│ 领域         │  01 / K12  升学考试              │
│ ○ 升学考试 5 │  从课堂到考场                    │
│   ├ 全部   5 │  ┌────────┬────────┬────────┐   │
│   ├ 小学   1 │  │ 小学   │ 初中   │ 高中   │   │
│   ├ 初中   1 │  └────────┴────────┴────────┘   │
│   └ 高中   3 │  [题库卡] [题库卡] [题库卡]      │
│ ○ 大学学业 5 │                                  │
│ ○ 职业资格 5 │                                  │
└─────────────┴──────────────────────────────────┘
```

设计依据：

- **左侧是「你在哪」**，右侧是「这里有什么」，符合文件管理器和电商分类的成熟心智。
- 学段默认展开在选中的领域下方，其他领域收起，避免一次性铺开 20 个学段。
- 右侧顶部先给领域概述，再给学段卡片（可点击进入该学段），最后才是题库卡；这样「只看高中」的用户不用先理解筛选器。
- 移动端左树折叠为顶部横向标签，内容区单列，不出现横向滚动条。

## 四、级联的四个层次

| 层 | 组件 | 决策粒度 |
| --- | --- | --- |
| L0 状态 | 首页三条路径 | 「我现在想干什么」 |
| L1 领域 | 侧边栏 / 左树 | 「哪个大方向」 |
| L2 学段 | 左树二级 / 学段卡 | 「哪个阶段」 |
| L3 题库 | 题库卡 | 「具体练哪一组」 |

任何一层都可以直接跳到下一层，但不会把四层同时铺在屏幕上。

## 五、练习策略：把「选什么」交给系统

四条策略对应四种场景；每日一练与薄弱项突破参考作答数据，部分策略会随机抽题：

| 策略 | 触发场景 | 配题算法 |
| --- | --- | --- |
| 每日一练 | 每天打开不知道练什么 | 对有记录的最弱 3 个领域加权，从权重最高的最多 5 个领域按配额抽题，每库最多取 2 题；不足时从全库随机补齐（不受每库上限约束），默认 10 题。过滤近期题后若不足，会重新抽取，可能包含近期题 |
| 薄弱项突破 | 明确知道自己差在哪 | 取正确率最低的 2 个领域，从其中随机抽 10 题 |
| 随机组卷 | 想检验真实水平 | 全库洗牌抽 12 题，不偏向任何领域 |
| 错题复习 | 考前回看 | 从全库筛选错题，按全库顺序取最多 20 题，不保证按错误次数排序 |

策略页会显式展示「本次配题依据」（如「当前最弱：职业资格 42%」），让用户理解为什么是这些题，而不是黑箱。

## 六、避免「AI 式列表」的具体规则

1. **同一屏最多一个列表**：其余信息用卡片网格、时间线、统计条承载。
2. **列表必须带层级线索**：题库行不只有标题，还有所属领域、考试类型、题量、时长。
3. **筛选器不超过两组**：领域用树，学段用标签，关键词用搜索框，三者不同时铺开。
4. **每层都有返回路径**：面包屑 + 顶部返回 + 侧边栏高亮，三条冗余但一致。
5. **空态给出下一步**，不给「暂无数据」。

## 七、响应式断点

| 断点 | 侧边栏 | 题库总览 | 练习页 |
| --- | --- | --- | --- |
| ≥ 1080px | 固定 248px | 左树 + 右内容 | 题目 + 右侧答题卡 |
| 900–1080px | 固定 220px | 左树 190px | 题目 + 右侧答题卡 |
| ≤ 900px | 抽屉 + 遮罩 | 单列，树折叠为顶部标签 | 单列，答题卡变底部抽屉 |
| ≤ 560px | 抽屉 | 单列卡片 | 单列，操作按钮纵向排列 |
