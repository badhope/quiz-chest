# 题库导入格式

题小星支持把自有题目导入为本地题库：数据只保存在本机的设备数据库（桌面端为 SQLite，Web 端为 IndexedDB），不上传、不注册。导入入口：侧边栏「题库总览」→ 页面上的「导入题库」，或直接访问 `/import`。

## 五种入口

| 格式 | 扩展名 | 适合 |
| --- | --- | --- |
| JSON | `.json` | 选项多于 4 个、需要带题库元数据、程序化导出 |
| CSV | `.csv` | 从 Excel / WPS / Google Sheets 导出，UTF-8 编码 |
| Excel | `.xlsx` | 已有表格题库，沿用与 CSV 相同的列名 |
| 文本模板 | `.docx` / `.txt` / `.md` | 已有 Word 文档，按题号、选项、答案、解析排好 |
| PDF 文字层 | `.pdf` | 有可复制文字的电子试卷；扫描件不算 |

单次最多 **2000 题**；题干重复的行会被跳过并提示。

## JSON 格式

顶层是一个对象：

```json
{
  "title": "前端面试冲刺",
  "subtitle": "跳槽复习",
  "description": "按面试真题整理",
  "exam": "前端面试",
  "level": "进阶",
  "durationMin": 30,
  "tags": ["JavaScript", "面试"],
  "questions": [
    {
      "type": "single",
      "stem": "typeof null 的结果是？",
      "options": ["\"null\"", "\"object\"", "\"undefined\"", "\"boolean\""],
      "answer": ["B"],
      "explanation": "typeof null 返回 object，判断 null 应使用 x === null。",
      "difficulty": 2,
      "tags": ["类型"]
    },
    {
      "type": "multiple",
      "stem": "下列哪些声明会创建块级作用域？",
      "options": ["var", "let", "const", "function"],
      "answer": "BC",
      "explanation": "let 与 const 是块级作用域，var 是函数作用域。",
      "difficulty": 1,
      "tags": ["作用域"]
    },
    {
      "type": "judge",
      "stem": "0.1 + 0.2 === 0.3 成立。",
      "options": ["正确", "错误"],
      "answer": "B",
      "explanation": "IEEE 754 浮点数存在精度误差，结果为 false。",
      "difficulty": 2,
      "tags": ["浮点数"]
    },
    {
      "type": "fill",
      "stem": "光合作用的场所是？",
      "answerText": ["叶绿体", "叶绿体。"],
      "explanation": "叶绿体含有叶绿素，是光合作用的场所。",
      "difficulty": 2,
      "tags": ["光合作用"]
    },
    {
      "type": "short",
      "stem": "光合作用需要哪两个条件？",
      "answerText": ["光照和叶绿体"],
      "keywords": ["光照", "叶绿体"],
      "explanation": "光照提供能量，叶绿体完成反应。",
      "difficulty": 2,
      "tags": ["光合作用"]
    }
  ]
}
```

题目也接受简写：选择题的 `options` 直接给数组（等价于 `optionA…optionF`），`answer` 给字母字符串或下标数组均可。填空题和简答题不写 `options` / `answer`，改写 `answerText`；简答题还要写 `keywords`。

### 文本题怎么判分

- 填空题：`answerText` 可以给多个可接受答案，数组或 `|` 分隔字符串都行。判分时先把全半角、大小写、空格和常见标点归一化，再与任一答案全等比较。
- 简答题：`keywords` 里的关键词全部出现在作答里才算对；不判断语义，也不调用模型。它是一套可解释的关键词判分，不等同于老师的主观评分。
- 简答题至少写一个关键词。没有关键词的简答题会在导入时被跳过，避免出现“写了答案却无法判分”的题。
- 归一化只处理表面差异，不会把“光照和叶绿体都不需要”判成对；关键词判分只能确认词是否出现，作答是否符合逻辑仍要自己看解析。

## CSV 格式

UTF-8 编码，首行表头，含逗号或换行的单元格用双引号包裹：

```csv
stem,optionA,optionB,optionC,optionD,answer,answerText,keywords,explanation,type,difficulty,tags
typeof null 的结果是？,"null","object","undefined","boolean",B,,,typeof null 返回 object,single,2,类型
下列哪些声明会创建块级作用域？,var,let,const,function,BC,,,"let 与 const 是块级作用域",multiple,1,作用域
0.1 + 0.2 === 0.3 成立。,正确,错误,,,B,,,浮点精度误差导致结果为 false,judge,2,浮点数
光合作用的场所是？,,,,,,叶绿体|叶绿体。,,"叶绿体含有叶绿素，是光合作用的场所",fill,2,光合作用
光合作用需要哪两个条件？,,,,,,光照和叶绿体,光照|叶绿体,"光照提供能量，叶绿体完成反应",short,2,光合作用
```

CSV 可以带一个可选的 `title` 列来命名题库；该列取第一行的非空值作为整份 CSV 的题库名。
若省略，则题库名落为「未命名题库」。

表头仍然保留 5 个基础列：`stem`、`optionA`、`optionB`、`answer`、`explanation`。文本题把选项列留空，答案写在 `answerText`，简答题再写 `keywords`。其余列缺省时使用默认值，因此最简的选择题 CSV 可以短到这样：

```csv
stem,optionA,optionB,answer,explanation
1+1 等于几,1,2,B,基础加法运算
```

只做填空题时，仍然需要保留空的 `optionA`、`optionB` 和 `answer` 列，因为表头结构共用一份；值留空即可。

`answer` 列支持多种常见写法，都会解析为同一组选项下标：

| 写法 | 解析结果 |
| --- | --- |
| `B` | `[1]` |
| `BC` | `[1, 2]` |
| `B;D` / `B,D` / `B、D` / `B/D` | `[1, 3]` |
| `1,3`（1 起始下标） | `[0, 2]` |

## Word / TXT / Markdown / PDF 模板

文本入口只认一种稳定的题号模板，不猜测任意排版。模板可以从导入页下载，也可以直接在页面里粘贴。

```text
# 我的题库

1. 2 + 2 等于多少？
A. 3
B. 4
C. 5
D. 6
答案：B
解析：2 + 2 = 4，基础加法。
难度：1
考点：加法

2. 下列哪些是偶数？【多选】
A. 2
B. 3
C. 7
D. 8
答案：A、D
解析：2 和 8 能被 2 整除，是偶数。

3. 光合作用的场所是？【填空题】
答案：叶绿体|叶绿体。
解析：叶绿体含有叶绿素，是光合作用的场所。

4. 光合作用需要哪两个条件？【简答题】
参考答案：光照和叶绿体。
关键词：光照|叶绿体
解析：光照提供能量，叶绿体完成反应。
```

规则：

- 题号支持 `1.`、`1、`、`第 1 题` 三种写法；选项按 `A.` 到 `F.` 排列。
- 题型可在题干前写 `【单选】【多选】【判断】【填空】【简答】`，也可以写 `题型：多选`；不写时会按答案字母数量推断选择题，没有选项且答案不像「正确/错误」时按填空题处理。
- 答案写 `答案：B` 或 `答案：A、D`；判断题可以只写 `答案：正确`，会自动补成「正确 / 错误」两个选项。
- 解析写在 `解析：…` 后面，可以续多行；不写解析会补一句占位并提示。
- `.docx` 只读取正文段落，不保留字体、表格样式；旧版 `.doc` 请先另存为 `.docx`。
- `.pdf` 只读文字层。判断方法：在阅读器里能选中、复制题干和选项，才有文字层；整页是图片的扫描件会提示「没有可提取的文字层」，应用不内置 OCR。
- 填空题写 `答案：叶绿体|叶绿体。`；简答题写 `参考答案：…` 和 `关键词：光照|叶绿体`。简答题缺关键词、文本题缺参考答案都会被跳过。
- 题干重复的题会被跳过，并在预览页逐条列出；选择题选项少于 2 个同样跳过。

文本模板支持单选、多选、判断、填空、简答五种题型。文本题不会渲染选项，作答时显示输入框；简答题按关键词全命中判分。

## PDF 文字层

PDF 入口不是 OCR。它只读取 PDF 里已有的文字层，所以：

- 电子生成的试卷、从 Word 导出的 PDF，通常能直接导入。
- 扫描件、拍照转的 PDF、把图片贴进文档后打印的 PDF，没有文字层，会直接拒绝并提示先用系统 OCR 或扫描工具转成文本。
- 读取上限为 60 页、200 万字符；超过会在预览页提示截断，拆成多份再导入。
- PDF 里的题号、选项、答案和解析仍然按上面的题号模板解析。排版越接近「一题一段、选项各占一行」，识别越稳；双栏、题号嵌在段落中间、答案和解析混排的卷子，可能需要先在源文件里整理。
- PDF 的元数据标题只作为兜底，正文里写 `# 题库名` 仍然优先。


## 字段说明

### 题库元数据（仅 JSON，均可省略）

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `title` | string | 未命名题库 | 题库名，同时决定题库 ID |
| `subtitle` | string | 导入题库 | 一句话简介 |
| `description` | string | — | 题库详情页描述 |
| `exam` | string | 同 title | 考试/用途标签 |
| `level` | `入门` / `进阶` / `挑战` | 入门 | 难度档位 |
| `durationMin` | number | 10 | 模拟考试限时（分钟），1-300 |
| `tags` | string[] | — | 考点标签 |
| `accent` | `#RRGGBB` | 自动分配 | 主题色 |
| `icon` | string | book | 图标键（见 taxonomy） |

### 题目字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `stem` | 是 | 题干，重复题干跳过 |
| `options` / `optionA`…`optionF` | 选择题必填 | 至少 2 个选项；JSON 可用 `options` 数组，CSV 用列。文本题留空 |
| `answer` | 选择题必填 | 字母（`B` 或 `BC`）或下标数组（`[1]`、`[1,2]`）。文本题留空 |
| `answerText` | 文本题必填 | 填空/简答的参考答案；多个可接受答案用数组或 `|` 分隔 |
| `keywords` | 简答题必填 | 判分关键词，数组或 `|` 分隔；全部出现才算对 |
| `explanation` | 是 | 解析，至少 4 个字符 |
| `type` | 否 | `single`（默认）/ `multiple` / `judge` / `fill` / `short` |
| `difficulty` | 否 | 1/2/3，默认 2 |
| `tags` | 否 | 分号或竖线分隔（CSV），JSON 用数组 |

### 校验规则（逐行报错，不整批拒绝）

- `single` / `judge` 只允许一个答案；`judge` 必须恰好 2 个选项。
- `multiple` 允许 2-6 个答案字母。
- 答案字母超出选项范围会报「答案 X 超出选项范围」。
- 缺题干、缺答案、选项不足 2 个、解析过短都会定位到行号。
- 通过校验的行正常导入，问题行在预览页逐条列出，可返回修改或确认导入。

## 数据存储与删除

- 导入的题库存放在设备数据库：桌面端写入 `banks` / `questions` 表，Web 端写入 IndexedDB 的同名对象仓库。
- 旧版浏览器 `localStorage` 数据不再自动迁移；需要旧数据时先用旧版导出完整备份，再到新版恢复。
- 删除题库：「题库总览」→ 题库卡「删除」。学习记录不随之删除，但题目引用会失效。
- 「设置 → 显示内置题库」可隐藏随包内容，只显示你自己的题库。

## 题小星题库包（tixing-bank）

当前包版本为 **v2**。旧版 v1 包可直接导入，应用会在预览时自动迁移并提示版本升级；高于当前版本的包会被拒绝，防止字段静默丢失。

从「我的题库」导出的文件使用 `.tixing.json` 扩展名，包顶层包含：

```json
{
  "format": "tixing-bank",
  "version": 2,
  "exportedAt": "2026-10-31T00:00:00.000Z",
  "bank": { "title": "我的题库", "questions": [] }
}
```

当前支持 `version: 1` 和 `version: 2`：

- v1 导入时自动补齐 v2 默认字段，并在预览页显示升级提示。
- 高于当前版本的包会拒绝导入，避免静默丢字段。
- 普通 JSON 导入与 `tixing-bank` 包导入走不同校验路径。

## 白标配置

白标部署不需要修改源码。支持编译期环境变量和运行时全局配置；运行时配置优先级更高。

| 配置 | 环境变量 | 默认 |
| --- | --- | --- |
| 产品名 | `VITE_BRAND_NAME` | 题小星 |
| 英文副标题 | `VITE_BRAND_EN` | TiXing |
| Logo 字符 | `VITE_BRAND_MARK` | 题 |
| 主色 | `VITE_BRAND_ACCENT` | `#a8442a` |
| 浅色背景 | `VITE_BRAND_ACCENT_SOFT` | `#f3e3dc` |
| 页脚文案 | `VITE_BRAND_FOOTER` | 导入自有题库 · 离线练习 · 数据留在本机 |

运行时注入示例：

```html
<script>
  window.__TIXING_BRAND__ = {
    productName: '教研通',
    productEn: 'JIAOYAN',
    logoMark: '研',
    accent: '#1F7A5C',
    accentSoft: '#DFF0E8',
    footerNote: '内部培训专用'
  }
</script>
```
